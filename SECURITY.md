# Security Policy

This repository is a defensive, simulation-only research platform. It must not be used to target real PLCs, robots, industrial networks, or production equipment. Attack modules are abstract manipulations of synthetic in-memory telemetry.

Report software vulnerabilities privately using GitHub private vulnerability reporting when available. Do not publish sensitive exploit details in public issues.

Simulation thresholds, controller states, maintenance decisions, and quality rules are illustrative and are not deployment-ready safety or security controls.
