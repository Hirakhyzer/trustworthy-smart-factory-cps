# Contributing

Contributions are welcome when they improve scientific clarity, reproducibility, modeling, diagnostics, testing, or documentation.

Before opening a pull request:
1. run `pytest` and relevant scenario scripts;
2. document units and parameter provenance;
3. distinguish synthetic output from measured data;
4. record random seeds and attack windows;
5. add tests for behavioral changes;
6. keep cybersecurity scenarios abstract, defensive, and simulator-only.
